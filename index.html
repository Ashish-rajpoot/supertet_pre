How to use

  1. No internet? No problem - open the site once, then it works offline.
  2. On a phone: use the browser menu → Add to Home screen for an app-like icon.
  3. Add questions: the site owner uploads an Excel/CSV/JSON file from the Questions page.
  4. Results: every finished test is saved on the device and summarised on the Progress page.
